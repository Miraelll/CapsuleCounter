# CapsuleCounter

Десктопное приложение для автоматического распознавания, подсчета и измерения размеров капсул на микроскопических фотографиях. 

Программа обрабатывает изображения с помощью алгоритмов компьютерного зрения, позволяет проводить калибровку по сетке микроскопа (например, камере Горяева) и генерирует подробные отчеты в форматах CSV и XLSX.

## 🚀 Ключевые возможности

* **Автоматическое распознавание:** Поиск капсул на изображении с использованием детекторов границ (Canny) и трансформации Хафа, а также анализ замкнутых изолированных контуров.
* **Независимая площадь покрытия:** Альтернативный метод оценки количества капсул через фотометрическую сегментацию пикселей и вычисление площади с автоматическим удалением линий сетки.
* **Настройка изображения "на лету":** Динамическое изменение яркости и четкости изображения для улучшения качества выделения контуров. Мульти-расчет при вводе нескольких параметров.
* **Калибровка масштаба:** Перевод пикселей в микрометры (мкм) путем выделения отрезков известной длины (например, 50 мкм для малого квадрата).
* **Ручная корректировка:** Добавление, удаление, перемещение отметок и групповое удаление ложных находок прямоугольными или круглыми зонами.
* **Пакетная обработка:** Параллельный анализ целой серии снимков с автоматическим пропуском дубликатов.
* **Экспорт отчетов:** Формирование гистограмм распределения размеров (Matplotlib), выгрузка данных в CSV и создание единого XLSX-файла со встроенными размеченными фотографиями без внешних зависимостей.

## 🛠 Стек технологий

* **Язык:** Python 3
* **Компьютерное зрение:** OpenCV (`opencv-python-headless`), NumPy
* **Работа с изображениями:** Pillow (`PIL`)
* **Графики:** Matplotlib
* **Интерфейс:** `tkinter` (со встроенными стилями `ttk`)
* **Сборка:** PyInstaller (упаковка в единый автономный `.exe`)

## 📦 Запуск и установка

Утилита может работать как самостоятельный исполняемый файл, не требующий установки Python на целевом компьютере.

### Вариант 1: Использование готового .exe
1. Перейдите в раздел [Releases](../../releases) и скачайте `CapsuleCounter-v1.6.exe`.
2. Запустите скачанный файл (программа работает автономно).
